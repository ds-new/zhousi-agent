# 生产级完善：验收合同

延续上一轮全部工作区改动，不回退或覆盖。目标为共享 CP、客户独立 DP、可配置多副本；真实模型效果和集群外部环境验收必须如实区分。

1. 评估/进化：禁止无taskId/batch的trace发布，冻结评估任务，保留集和候选门禁，失败/重复调用安全。先独立回归，再修改相关模块。
2. CP持久化：移除每请求全租户重写，事务保证单次业务操作原子，跨实例并发与恢复；调度锁提供跨实例互斥。
3. DP状态：持久化接口、Postgres多副本Session互斥和Workspace memory原子更新；过期清理、关闭回收。
4. 服务边界：租户service identity、DP固定租户、内部接口认证、严格JSON/额度限制；工具审批绑定准确，不能更换凭据作用域。
5. 会话执行：请求幂等、真实计量可靠回传、失败恢复；人工ask审批限于精确工具调用、过期和一次性消费。
6. 运维：启动生产配置校验、健康/就绪、shutdown、CI与部署配置、最小权限；实际协议、数据库、负载/恢复测试。
7. 最终逐项矩阵：通过了哪些生产合同，哪些需要外部真实凭据/集群/业务SLO证据，保留所有未通过项。

并行边界：数据库子模块、评估子模块独立实现；根线程负责DP状态/执行和CP接口集成。共享domain/types变更先通知，server.ts由根线程修改。

执行结果：上述仓库内整改与回归已完成，214 项测试通过。逐项结论及不可用本地测试替代的外部验收条件记录在 `docs/reports/production-readiness-assessment.md`，不将外部验收标记为完成。
